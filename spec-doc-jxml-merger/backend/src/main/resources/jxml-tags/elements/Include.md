# Include

Aussi appelé **Document Part** ou **Bloc Commun**. Bloc de code faisant partie d'un formulaire, conçu pour être réutilisable à souhait, à l'image d'une librairie de fonctions informatiques. Ce bloc peut représenter une liste de questions, un contenu mixte (questions, images, liens), une section (page) entière d'un formulaire, etc.

Source : documentation JWAY Campus, page "Lexique Jway - termes génériques" (https://campus.jway.eu/portal/documentation/step/3009).
