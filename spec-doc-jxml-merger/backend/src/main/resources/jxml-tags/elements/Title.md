# Title

Utilisé pour attribuer un nom ou un libellé aux différents composants d'un formulaire. Permet d'identifier clairement les sections ou groupes de contenus afin d'en faciliter la lecture et la structure.

## Composants pouvant utiliser l'élément Title

- `MetaContent`
- `QuestionSet`
- `ChoiceSet`
- `Section`
- `List`

## Attributs

| Attribut | Type | Description |
|---|---|---|
| `TradId` | — | Identifiant technique (ne pas modifier) |

Source : documentation JWAY Campus, page "Title" (https://campus.jway.eu/portal/documentation/step/2781).
