# Fonction getAttachmentUrl()

**Description **: Cette fonction retourne le lien du service de gestion des pièces jointes.

**Syntaxe **: **getAttachmentUrl()** retourne une valeur de type **String**

**Exemple **: getAttachmentUrl()
