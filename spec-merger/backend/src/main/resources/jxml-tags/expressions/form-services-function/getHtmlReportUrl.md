# Fonction getHtmlReportUrl()

**Description **: Cette fonction retourne le lien du rapport HTML associé au dossier.

**Syntaxe **: **getHtmlReportUrl()** retourne une valeur de type **String**

**Exemple **: getHtmlReportUrl()
