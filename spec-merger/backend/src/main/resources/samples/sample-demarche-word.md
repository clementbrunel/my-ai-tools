# Démarche d'exemple

Spécification fonctionnelle d'exemple — mêmes écrans que `sample-demarche.jxml`, pour tester le
pipeline complet (Word + JXML) sans fichier réel à disposition.

## Coordonnées

L'utilisateur saisit ses coordonnées de contact.

| Élément | Obligatoire | Description |
|---|---|---|
| Nom | Oui | Nom de famille de l'utilisateur |
| Prénom | Oui | Prénom de l'utilisateur |
| Email | Oui | Adresse email de contact |
| J'accepte de recevoir des communications par email | Non | Visible uniquement si l'email est renseigné |

## Pièce justificative

L'utilisateur dépose un justificatif de domicile (PDF, JPG ou PNG, 5 Mo maximum, un seul fichier).
