# my-money-hub

Agrégateur perso de comptes bancaires et d'assurance-vie — alternative auto-hébergée à Linxo/Bankin pour un usage strictement personnel.

Voir [`CLAUDE.md`](./CLAUDE.md) pour les détails techniques, l'état de couverture par banque et les prochaines étapes.

## Quickstart

```bash
cp .env.example .env   # puis éditer .env
docker compose up --build
```

- Frontend: http://localhost:3001
- API: http://localhost:8091
