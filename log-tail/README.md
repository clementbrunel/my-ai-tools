# log-tail

Visualiseur de logs temps réel, portage moderne et personnalisable de [BareTail](https://www.baremetalsoft.com/baretail/) :
suivi instantané de fichiers de toute taille, rotation gérée, surlignage regex, filtres, parseurs de
format, profils, vue fusionnée multi-fichiers — Windows, Linux, macOS.

> **Statut : phase de cadrage** — aucun code pour l'instant.
